Frequently Asked Questions

Common questions buyers usually ask before installation.

How does this module calculate incoming stock valuation?

The module uses true FIFO (First-In, First-Out) valuation. It evaluates inventory quantities against historical incoming stock moves (from newest to oldest), calculating weighted unit costs and allocating quantities across period brackets based on move dates.

Can I customize the period intervals?

Yes! You can specify any period length (e.g. 15, 30, 45, 60, 90 days). The module automatically computes 5 dynamic period brackets (e.g., 0-30, 31-60, 61-90, 91-120, 121+ Days) and updates all column headers across List, Pivot, PDF, and Excel reports.

Can I filter stock by warehouses and specific internal locations?

Yes, the wizard provides multi-warehouse and multi-location filters (including child locations) as well as filtering by specific products or product categories.

What export formats are supported?

You can view interactive reports on-screen (List, Pivot, Graph), download executive Landscape QWeb PDF reports with KPI summary cards, or export formatted Excel (.xlsx) spreadsheets with category subtotals and grand totals.
